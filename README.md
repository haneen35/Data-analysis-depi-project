# Data-analysis-depi-project
# Social Media & Marketing Campaign Analysis

## 📖 Project Overview
This project analyzes a 200,000-record dataset to identify trends in marketing ROI, channel performance, and audience engagement. The analysis was implemented across three platforms to demonstrate cross-functional data skills.

### Key Objectives
* **Financial Analysis:** Tracking Acquisition Cost vs. ROI over time.
* **Channel Strategy:** Comparing CTR and Conversion Rates across Google Ads, Facebook, and Influencers.
* **Audience Insights:** Segmenting engagement by Age, Gender, and Location.

## 🛠 Installation & Execution Guide

### 1. System Requirements
* **Power BI:** Microsoft Power BI Desktop (Latest Version).
* **Excel:** Microsoft Excel 2016 or newer (PC/Mac).
* **Tableau:** Tableau Public or Desktop.

### 2. Configuration Steps (Power BI)
1.  Download the `.pbix` file from this repository.
2.  Download the dataset `marketing_campaign_dataset.csv.xlsx`.
3.  Open Power BI Desktop.
4.  Go to **Home > Transform Data > Data Source Settings**.
5.  Select "Change Source" and browse to the location where you saved the dataset on your local computer.
6.  Click **Close & Apply**.

### 3. Running the Project
* **Power BI:** Open the file to interact with the "Executive," "Campaign," and "Audience" pages. Use the slicers on the left to filter the entire report.
* **Excel:** Open the file and enable editing. Use the Slicers to filter the Charts dynamically.
